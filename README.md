# Govard Book

Электронная читалка книги Джона Говарда *The State of the Prisons*.
Текст получен автоматическим распознаванием сканов и может содержать ошибки.

## Запуск

Нужен Python 3 и пакет PyMuPDF для отображения страниц PDF как изображений:

```sh
python -m venv .venv
. .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python reader.py
```

Откройте в браузере http://localhost:8080/. Чтобы выбрать другой порт, задайте переменную окружения `PORT`. Сервер должен оставаться запущенным во время чтения. Скан показывается в виде изображения; ссылка на исходный PDF остаётся доступной отдельно.

## Правки текста

Откройте разворот, нажмите «Редактировать текст», щёлкните по нужному абзацу и внесите изменения. Нажмите «Сохранить»; скан и исходный OCR-файл не изменяются. На странице «История правок» можно посмотреть предыдущие версии и вернуть последнюю версию каждого фрагмента. Несохранённые изменения остаются только в открытой вкладке.

Правки и история сохраняются в `text_edits.json` в папке проекта — сохраняйте резервную копию этого файла. Предыдущий инструмент замены слов использует отдельный `corrections.json`; ранее созданные замены сохраняются. Ручные правки конкретных фрагментов имеют приоритет над заменами слов.

## Проверка слитных слов

Для всех разворотов доступна кнопка «Проверка OCR». Сравнение двух OCR предлагает варианты пробелов; их необходимо сверять со сканом и принимать или отклонять по одному. Там же показаны возможные примечания и кавычки, обнаруженные автоматически. Они могут содержать ложные срабатывания и пропуски. Подтверждённые правки записываются в ту же историю, что и ручные правки; исходные файлы не меняются. Повторное OCR и описание метода находятся в `ocr_review/`.

## Проверка

После установки зависимостей запустите `python -m unittest discover -s tests -v`. Тесты создают временные файлы и не изменяют ваши сохранённые правки.

## Оформление и пометки качества

Особые макеты для выходных сведений, титульной страницы и эпиграфа (развороты 165, 163 и 161) сверены со сканами; сохранённые пользовательские правки имеют приоритет. Разворот 14 в исходном PDF повёрнут, в читалке его изображение отображается с исправленной ориентацией, сам PDF не меняется.

В выпадающем списке разворотов отмечены только визуально подтверждённые проблемы со сканом. В разделе «Проверка сканов» отдельно показаны также страницы, требующие проверки OCR. Низкая уверенность OCR или сложная таблица не означает плохое качество фотографии; перечень не гарантирует обнаружения всех проблем.

### Замена скана и снятие пометки

Под изображением любого разворота кнопка «Заменить скан» принимает один файл всего разворота: JPG, PNG или одностраничный PDF, до 20 МБ. Оригинальный PDF не изменяется; кнопка «Вернуть исходный скан» удаляет загруженную замену. Предыдущая замена при загрузке новой не сохраняется. Замены хранятся в `scan_overrides/`, пометки проверки — в `scan_quality.json`; сохраняйте эти файлы при переносе читалки. Они не доступны через прямые URL.

Пометки скана и OCR снимаются и возвращаются независимо друг от друга. При замене исходного скана его предупреждение не переносится на непроверенный загруженный файл; при возврате исходника снова показывается его предупреждение, если пользователь его не снимал. Сохранённые решения при замене не сбрасываются. Замена изображения не запускает OCR заново: текст и подсказки относятся к исходному скану.

### Статус сверки текста

Галочка «☑ OCR» в разделе проверки и на странице разворота обозначает, что текст разворота ещё не полностью сверен со сканом; она не означает плохое качество скана. На данном этапе базовый текст разворотов 5, 6, 151, 153, 161–165 сверён по оригиналам и оформлен отдельно; остальные отмечены для последующей работы. Сохранённые пользователем изменения всегда имеют приоритет. Если пользователь снял предупреждение самостоятельно, его решение сохраняется.

Таблицы V–VIII на разворотах 151–152 восстановлены в строках и столбцах по сканам; широкие таблицы подстраиваются под ширину страницы и остаются доступными для редактирования. На странице 152 сохранено напечатанное значение 49 за 1782–1783 годы, хотя сумма показанных в строке чисел равна 59; расхождение отмечено отдельно. Таблицы на разворотах 145–150 пока остаются в черновом OCR и требуют сверки.

### Поиск пропусков и дополнительные издания

Кнопка «Возможные пропуски» сравнивает текущие редактируемые фрагменты с повторным OCR, игнорируя пробелы и пунктуацию и выискивая возможный пропущенный текст между совпадающими участками. Это подсказки, а не автоматические правки: они могут быть ошибочными и неполными, особенно для сносок, таблиц и смещённых страниц. Исправления, сверенные с исходным сканом, внесены в базовые фрагменты разворотов 4, 7 и 9; пользовательские изменения по-прежнему имеют приоритет.

В той же проверке показываются найденные совпадения из загруженных DOCX, EPUB и PDF. DOCX и EPUB описывают издание William Eyres; PDF — отдельный скан Internet Archive. Это **не то же издание**, что используемые в читалке сканы Everyman's Library: текст, состав и расположение таблиц могут различаться, а электронные тексты содержат ошибки OCR. Материалы используются только для ручного сравнения и не перезаписывают текст книги.
