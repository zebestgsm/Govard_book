# Повторное распознавание книги

В файлах `N_0.txt` и `N_1.txt` — необработанный результат повторного распознавания половин скана разворота N (0 — левая, 1 — правая). Пустая левая половина первого скана не обрабатывалась. Использованы Tesseract.js 7.0.0 и английская модель `@tesseract.js-data/eng` 1.0.0; изображения отрендерены из исходных PDF с масштабом 2,5.

`suggestions.json` содержит предложения вставки пробелов: написание должно совпадать с первичным OCR по буквам без пробелов и встречаться во втором OCR как несколько слов. Алгоритм не гарантирует правильность: предложения нужно проверять по скану. Подтверждённые исправления и история хранятся в `text_edits.json` в корне проекта.

`annotations.json` содержит автоматически обнаруженные возможные примечания и кавычки с контекстом и номером строки повторного OCR. Среди них возможны ложные срабатывания, а некоторые настоящие сноски или цитаты могут быть пропущены; это не проверенная транскрипция. Текст из `annotations.json` не подменяет книгу.

Для пересборки индексов после получения OCR-файлов выполните `python ocr_review/build_review.py` из корня проекта. Первые три разворота сохраняются без перегенерации идентификаторов. Варианты для остальных разворотов должны пересобираться только с учётом совместимости сохранённых решений пользователя.
