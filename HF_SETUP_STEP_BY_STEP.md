# Вариант A: пошагово, со ссылками

Что делаем: даём **GitHub Actions** доступ к Hugging Face, чтобы модель перевода скачивалась
в CI (а не в песочнице, где сети до HF нет). Токен нужен только для двух вещей — снять лимиты
анонимных скачиваний и открыть доступ к вашим собственным копиям моделей. **Мне его присылать
не нужно и не следует**: он останется в GitHub, в код и логи не попадёт.

Важно: пока токена нет, пайплайн всё равно работает — публичные модели скачиваются анонимно.
Токен делает прогон устойчивее, а не «включает» его.

## Шаг 1. Создать токен Hugging Face (2 минуты)

1. Войдите на https://huggingface.co/login
2. Откройте https://huggingface.co/settings/tokens
3. Кнопка **New token**.
4. Имя: `govard-ci`. Тип: **Read** (не Write — писать в HF нам не нужно).
5. **Create token** → скопируйте строку, начинающуюся с `hf_...`.

Токен показывается один раз. Если потеряли — удалите и создайте новый, это нормально.

Что это даёт:
- снимает ограничения на анонимные скачивания больших моделей (иначе прогон может упасть
  на rate limit, особенно если запускать несколько раз подряд);
- открывает доступ к моделям, которые вы скопируете к себе (Вариант B) и к gated-моделям,
  если решим пробовать большие;
- в CI не будет «то работает, то 401» — типовая причина падений у анонимных прогонов.

## Шаг 2. Положить токен в GitHub Secrets (2 минуты)

1. Откройте репозиторий: https://github.com/zebestgsm/Govard_book
2. **Settings** (вкладка в верхнем меню репозитория; если не видно — у вас должны быть права
   администратора).
3. Слева: **Secrets and variables → Actions**.
4. Кнопка **New repository secret**.
5. **Name**: `HF_TOKEN` (ровно так, заглавными).
6. **Secret**: вставьте `hf_...`.
7. **Add secret**.

Проверка: секрет появится в списке как `HF_TOKEN` с датой обновления; значение посмотреть нельзя —
это нормально и правильно. В workflow он подставляется как `${{ secrets.HF_TOKEN }}` и в логи
не попадает.

Если хотите сделать это из терминала (не обязательно), с `gh`:

```sh
gh secret set HF_TOKEN --repo zebestgsm/Govard_book
# команда попросит вставить значение; в истории оно не сохранится
```

## Шаг 3. Запустить контрольный прогон (5–10 минут)

1. Откройте https://github.com/zebestgsm/Govard_book/actions
2. Слева выберите workflow **Build Russian translation draft**.
3. Справа **Run workflow** → ветка `arena/b1f6ea5c-govard-book`.
4. Заполните:
   - `model`: `Helsinki-NLP/opus-mt-en-ru` (базовая; для сравнения потом
     `Helsinki-NLP/opus-mt-tc-big-en-ru`);
   - `limit`: `31,87,141,95` — четыре контрольных разворота из разных регистров
     (иностранные тюрьмы, описание Ньюгейта, заключение, английская тюрьма с таблицей).
5. **Run workflow**.

Через ~5–10 минут в репозитории появятся:
- `translation_sources/ru-mt.json` — черновик по этим разворотам;
- `mt-report.md` — отчёт: числа, сноски, объём, запрещённые варианты;
- комментарий в issue №2 с логом;
- артефакт `mt-draft` (скачать можно со страницы запуска).

Логи: на странице запуска → **Translate** / **Check the draft against the source**.

## Что это даёт по существу

1. **Полнота.** Вход — выверенный текст: 637 абзацев, ни одного потерянного знака (616 619 против
   616 622 — разница в 3 символа на всю книгу). Пропусков абзацев и сносок не будет по построению,
   а не «на глазок».
2. **Связность вместо обрывков.** 169 мест, где предложение было разрезано между сегментами,
   теперь склеены до перевода. Именно из-за них старый слой давал «Крес-ТерФилд» и «провидец
   прокладывал дыру в полу».
3. **Колонтитулы не попадают в текст.** 23 вынуты в отдельное поле; больше не будет
   «48-го СЧЕТА ИНОСТРАННЫХ ПРИНСОВ».
4. **Числа и сноски под контролем.** Отчёт по каждому развороту показывает потери и добавления
   до того, как текст попадёт к вам. Старый слой терял числа в 65 % разворотов — это видно в цифрах,
   а не на веру.
5. **Лексические нормы.** 133 статьи глоссария с запрещёнными вариантами + автоматический поиск
   этих вариантов в готовом тексте. Один термин — одно решение на всю книгу.
6. **Разные регистры.** Отдельные правила для отчёта Говарда (формулы полей в 42 разворотах
   округов), юридического текста и моралистических отступлений.
7. **Воспроизводимость.** Любой прогон можно повторить: вход, модель, отчёт и логи фиксируются
   в репозитории и в артефактах.

## Что мне НЕ нужно от вас

- Не присылайте токен в чат — он мне не нужен и не поможет внутри песочницы.
- Не нужно ничего устанавливать локально.
- Не нужно платить: публичные модели бесплатны, GitHub Actions для публичного репозитория —
  без оплаты; лимит 300 минут на запуск укладывается в бесплатные 2000 минут/месяц.

## Если что-то пойдёт не так

| Симптом | Что делать |
|---|---|
| Прогон падает на скачивании модели | проверьте, что секрет называется ровно `HF_TOKEN`; повторите запуск |
| `401`/`403` от HF | токен удалён или истёк — создайте новый и обновите секрет |
| Прогон идёт дольше 300 минут | запустите по частям: `limit` = `1-40`, потом `41-80` и так далее (поддержку диапазонов добавлю по вашей просьбе) |
| Нет правки в ветке после прогона | посмотрите шаг «Commit the draft and the report»: вероятно, не хватило прав на запись |
| Хочется другую модель | впишите её имя в поле `model` — код не меняется |
